# Контрольный список выпуска

Перед публикацией материала выполнить проверки.

1. **Методологическая проверка.** Определения, формулы, предпосылки, интерпретации и ограничения сверены с `STATISTICAL_ACCURACY.md`.
2. **Численная проверка.** Ключевые значения пересчитаны по `data/heart-disease.csv`; результат Уэлча согласован со своим доверительным интервалом.
3. **Проверка источников.** Ссылки активны, версии стандартов актуальны, источники подтверждают утверждения.
4. **Редакционная проверка.** Терминология единообразна, повторы устранены, сокращения расшифрованы.
5. **Проверка комплектности.** README, сценарий, презентация, данные, словарь данных и литература синхронизированы.
6. **Визуальная проверка.** Оба PDF собраны, просмотрены, QR-коды и ссылки проверены.

Статусы: `PASS`, `CONDITIONAL`, `FAIL`.

Критическая ошибка в статистической интерпретации блокирует выпуск.
