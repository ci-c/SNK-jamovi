# Требования к статистической точности

Документ фиксирует критерии проверки методологических утверждений в материалах заседания.

| ID | Требование | Критерий приёмки |
|---|---|---|
| AC-01 | Каждое существенное утверждение подтверждено источником или корректным выводом из метода | В сценарии указан источник формулы или метода |
| AC-02 | Специальный термин определён до использования | Первое упоминание сопровождается пояснением |
| AC-03 | Для метода указан исследовательский вопрос и тип данных | Метод не представлен как универсальный |
| AC-04 | Предпосылки относятся к конкретному методу | Нет правила «нормальность определяет всё» |
| AC-05 | Указаны ограничения правила или метода | Есть явная оговорка при упрощении |
| AC-06 | Вывод не выходит за пределы дизайна и модели | Ассоциация не названа причинным эффектом |
| AC-07 | Приведены оценка эффекта и неопределённость | По возможности указаны эффект и интервал |
| AC-08 | Статистическая и клиническая значимость различаются | Оба аспекта упомянуты в интерпретации |
| AC-09 | Используются действующие версии стандартов | CONSORT 2025 применяется для РКИ |
| AC-10 | Учебное упрощение не создаёт ложного правила | Оговорка приведена в том же блоке |

## Числа и примеры

| ID | Требование | Критерий приёмки |
|---|---|---|
| ST-01 | Указан датасет и преобразования | Есть ссылка на CSV и словарь данных |
| ST-02 | Расчёт воспроизводим | Приведены переменные и настройки |
| ST-03 | Статистика, df, p, эффект и интервал относятся к одной модели | Нет смешения Student и Welch |
| ST-04 | Округление не искажает смысл | Единицы и направление разности указаны |
| ST-05 | Для каждого анализа указан свой n | Числа 130, 57, 46, 25/31 не перемешаны |
| ST-06 | Пропуски и обработка описаны | Указано число пропусков и способ обработки |
| ST-07 | Множественность описана | Указано, какие сравнения корректировались |
| ST-08 | Важные числа сверены независимо | Есть пересчёт по CSV или сверка с таблицей |
