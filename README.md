# Введение в медицинскую статистику

Материалы заседания СНК Кафедры медицинской информатики и физики СЗГМУ им. И. И. Мечникова. Заседание проводится совместно со СНК кафедры педиатрии и детской кардиологии СЗГМУ им. И. И. Мечникова.

- **Дата первого заседания:** 27 ноября 2026 года, 17:00.
- **Место:** коворкинг в библиотеке, гибридный формат.
- **Формат:** формально одно заседание на 60 минут. Материал подготовлен с запасом, редактура и урезание будут выполнены позже.
- **Аудитория:** студенты 1–3 курсов, около 10 человек.

## Структура заседания

- Вступление, слайды 1–8: титул, материалы, план, Jamovi и ссылки.
  - Титул и материалы, слайды 1–2.
  - План заседания, слайд 3.
  - Цель статистики, Jamovi и ссылки, слайды 4–8.
- Данные, слайды 9–14: импорт, структура, подготовка, пропуски, словарь данных и типы переменных.
- Описательная статистика, слайды 15–19: показатели, запись результата, асимметрия, эксцесс и преобразования.
- Нормальность, слайды 20–22: критерий Шапиро–Уилка и выбор критерия.
- Сравнение групп, слайды 23–31: выборки, t-критерий, p-значение, доверительный интервал, эффект, мощность и дополнительные критерии.
- Корреляция и регрессия, слайды 32–38: корреляция, линейная и множественная регрессия, проверки модели.
- Категориальные данные, слайды 39–42: таблица сопряжённости, хи-квадрат, критерий Фишера и логистическая регрессия.
- Графики, слайды 43–51: базовые графики, элементы реальных статей и подписи.
- Байесовский статистический вывод, слайды 52–65: априор, апостериор, байесовский фактор, оценивание, MCMC и ограничения.
- Чтение клинической статьи, слайды 66–87: дизайн, таблицы, графики, эффекты, чек-лист и ответы.
- ИИ, слайды 88–90: риск и вспомогательная роль.
- Итоги, слайды 91–94: выводы, литература и контакты.

## Установка Jamovi

1. Откройте страницу загрузки по адресу <https://www.jamovi.org/download.html>.
2. Для Windows и macOS выберите обычный установщик. Для Linux используйте команду `flatpak install flathub org.jamovi.jamovi`.
3. Программа распространяется бесплатно, работает локально и не требует написания кода.

## Датасет


Переменная `target` принимает значение 1 при наличии болезни сердца и 0 при её отсутствии. Пустые ячейки имеются в колонках `ca` (4 значения) и `thal` (2 значения); Jamovi импортирует их как пропуски.

Типы переменных устанавливаются до расчётов. Номинальные переменные: `sex`, `cp`, `fbs`, `restecg`, `exang`, `slope`, `ca`, `thal`, `target`. Непрерывные переменные: `age`, `trestbps`, `chol`, `thalach`, `oldpeak`.

Для импорта откройте меню файла в Jamovi, выберите команду `Open` и укажите файл `heart-disease.csv`. Внизу окна появятся счётчики 303 наблюдения и 14 переменных.

## Сборка

Для сборки требуется LuaLaTeX и шрифт Times New Roman. Каждый файл собирается двумя последовательными вызовами `lualatex`.

```bash
cd presentation
lualatex -interaction=nonstopmode 'Презентация-Статистика-Jamovi-v1.tex'
lualatex -interaction=nonstopmode 'Презентация-Статистика-Jamovi-v1.tex'
cd ..
lualatex -interaction=nonstopmode 'Сценарий-заседания.tex'
lualatex -interaction=nonstopmode 'Сценарий-заседания.tex'
```

## Правила работы с данными

Переменная `target` получена из исходной переменной UCI `num` с значениями 0–4. Значение 0 соответствует отсутствию болезни, значения 1–4 превращены в `target = 1`. Такое преобразование теряет градацию тяжести. Типы переменных и коды категорий приведены в `data/DATA_DICTIONARY.md`.
