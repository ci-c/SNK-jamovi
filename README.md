## Установка Jamovi

1. Откройте страницу загрузки по адресу <https://www.jamovi.org/download.html>.
2. Для Windows и macOS выберите обычный установщик. Для Linux используйте команду `flatpak install flathub org.jamovi.jamovi`.
3. Программа распространяется бесплатно, работает локально и не требует написания кода.

## Датасет

Источник набора данных: [UCI Machine Learning Repository, Heart Disease](https://archive.ics.uci.edu/dataset/451/heart+disease), вариант Cleveland. Файл содержит 303 пациента и 14 переменных. Персональные данные пациентов в материалах не используются.

Переменная `target` принимает значение 1 при наличии болезни сердца и 0 при её отсутствии. Пустые ячейки имеются в колонках `ca` и `thal`; Jamovi импортирует их как пропуски.

Типы переменных устанавливаются до расчётов. Номинальные переменные: `sex`, `cp`, `fbs`, `restecg`, `exang`, `slope`, `ca`, `thal`, `target`. Непрерывные переменные: `age`, `trestbps`, `chol`, `thalach`, `oldpeak`.

Для импорта откройте меню файла в Jamovi, выберите команду `Open` и укажите файл `heart-disease.csv`. Внизу окна появятся счётчики 303 наблюдения и 14 переменных.

## Сборка

Для сборки требуется LuaLaTeX и шрифт Times New Roman. Каждый файл собирается двумя последовательными вызовами `lualatex`.

```bash
cd presentation
lualatex -interaction=nonstopmode 'Презентация-Статистика-Jamovi-v1.tex'
lualatex -interaction=nonstopmode 'Презентация-Статистика-Jamovi-v1.tex'
cd ..
lualatex -interaction=nonstopmode 'Сценарий-заседания.tex'
lualatex -interaction=nonstopmode 'Сценарий-заседания.tex'
```

## Правила работы с данными

Персональные данные пациентов нельзя передавать в публичные чаты и неодобренные аналитические сервисы. Это нарушает требования конфиденциальности и может нарушать закон. В учебном заседании используются только открытые и обезличенные наборы данных; допустимы сервисы, официально разрешённые для такой обработки. любой код или метод, предложенный ИИ, проверяется на учебном наборе и сверяется с документацией.
