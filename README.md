## Установка Jamovi

1. Перейдите на [jamovi.org](https://jamovi.org) → **Install**.
2. Windows и macOS — обычный установщик; Linux — flatpak: `flatpak install flathub org.jamovi.jamovi`.
3. Jamovi бесплатный, работает локально на компьютере, код писать не нужно.

## Датасет: heart-disease.csv

Источник: [UCI Machine Learning Repository — Heart Disease](https://archive.ics.uci.edu/dataset/451/heart+disease), набор Cleveland (303 пациентов, 14 переменных). Открытые данные, реальных данных пациентов в материалах нет.

Кодировка файла: `target` — **1: есть болезнь сердца (стеноз > 50%), 0: нет**. Пропуски (пустые ячейки) есть в `ca` и `thal` — при импорте они становятся отсутствующими значениями.

| Колонка | Описание |
|---|---|
| `age` | Возраст, годы |
| `sex` | Пол: 1 — мужской, 0 — женский |
| `cp` | Тип боли в груди (1–4) |
| `trestbps` | Артериальное давление в покое, мм рт. ст. |
| `chol` | Сывороточный холестерин, мг/дл |
| `fbs` | Глюкоза натощак > 120 мг/дл: 1/0 |
| `restecg` | ЭКГ в покое (0–2) |
| `thalach` | Максимальная частота сердечных сокращений |
| `exang` | Стенокардия при нагрузке: 1/0 |
| `oldpeak` | Депрессия ST при нагрузке |
| `slope` | Наклон сегмента ST (1–3) |
| `ca` | Крупных сосудов на ангиографии (0–3), есть пропуски |
| `thal` | Дефект перфузии (3/6/7), есть пропуски |
| `target` | 1 — есть болезнь сердца, 0 — нет |

### Импорт в Jamovi

Меню-файл слева сверху → **Open** → выбрать `heart-disease.csv`. Внизу окна должно быть **303 наблюдения, 14 переменных**.

## Сборка презентации

Требуется LaTeX с поддержкой LuaLaTeX и шрифт Times New Roman:

```bash
cd presentation
lualatex -interaction=nonstopmode 'Презентация-Статистика-Jamovi-v1.tex'
lualatex -interaction=nonstopmode 'Презентация-Статистика-Jamovi-v1.tex'  # второй прогон — счётчик кадров
```

## Правила работы с данными (коротко)

- В аналитику и в ИИ-сервисы не загружаются персональные данные пациентов (PHI) — только открытые и учебные наборы.
- ИИ — инструмент, а не врач: любой предложенный им код или метод проверяется на учебных данных и в документации.
